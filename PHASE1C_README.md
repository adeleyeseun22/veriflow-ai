# VeriFlow AI — Phase 1C Frontend Identity and Workspace UI

This overlay adds the frontend authentication and protected workspace experience without changing the approved public landing page.

## Added routes

- `/register`
- `/login`
- `/onboarding`
- `/dashboard`

## Added capabilities

- Cookie-based authenticated API requests
- CSRF-aware mutation requests
- Registration and login forms
- Workspace onboarding
- Protected dashboard
- Workspace selector
- Audit trail view
- Logout
- Responsive application shell
